Etsy AI Agent Pipeline

4-agent autonomous print-on-demand system · scout → design → list → fulfill
01 /04
🔍
Scout Agent
market intelligence · trend detection · niche analysis
Inputs
  • Etsy search API (bestsellers, trending)
  • Category/niche seed keywords
  • Price range filters
  • Review count thresholds
What it extracts
  • Top-selling niches + sub-niches
  • Price points & listing structure
  • Tag/keyword patterns
  • Style themes (not designs)
  • Seasonal demand signals
Tech
Python Etsy API v3 Claude Sonnet Playwright Supabase
TREND BRIEF JSON → niche, style keywords, price target
02 /04
🎨
Design Agent
original artwork generation · prompt engineering · variant creation
Inputs
  • Trend brief from Scout
  • Style descriptors (NOT copied designs)
  • Product type (tee, mug, poster…)
  • Color palette constraints
What it outputs
  • Original AI-generated artwork (PNG)
  • Print-ready at 300dpi / transparent bg
  • 3–5 colorway variants per design
  • Mockup images for listing photos
Tech
fal.ai FLUX Pro Claude Sonnet Sharp (resize) Placeit API
DESIGN PACKAGE → PNG files + metadata + mockups
03 /04
📦
Listing Agent
seo copywriting · etsy api · product publishing
Inputs
  • Design package + metadata
  • Trend brief (keywords, price)
  • Printful product catalog IDs
  • Etsy shop credentials
What it publishes
  • SEO-optimized title (140 chars)
  • Long-form description with keywords
  • 13 Etsy tags (exact match + long tail)
  • Variants (sizes, colors) + pricing
  • Shipping profiles auto-attached
Tech
Etsy API v3 Claude Sonnet Node.js / TS OAuth 2.0 Supabase
ETSY ORDER WEBHOOK → order_id, item, buyer address
04 /04
🚚
Fulfillment Agent
order routing · printful sync · tracking · exception handling
Inputs
  • Etsy order webhook payload
  • Design file lookup (Supabase)
  • Printful product variant map
What it does
  • Creates Printful order via API
  • Polls for tracking number
  • Posts tracking back to Etsy
  • Handles failures / alerts to Slack
  • Logs margin per order to DB
Tech
Printful API Node.js / TS Etsy API v3 Railway cron Resend email

Recommended full stack
Orchestration / Backend
Python (agents) + Node.js/TS (APIs)
Python leads for AI/scraping tasks. Your TS skills carry over for the Etsy/Printful API layer.
AI Backbone
Claude Sonnet 4 (via API)
Prompt chaining between agents. Structured JSON outputs for each handoff.
Image Generation
fal.ai + FLUX Pro 1.1
Best quality/cost ratio for POD. Outperforms DALL-E for commercial print work. ~$0.05/image.
Database
Supabase (Postgres)
Stores designs, listings, orders, margin tracking. Already in your NgTenant stack.
Hosting / Scheduling
Railway
Cron jobs for Scout runs. Webhook receiver for Etsy orders. Also already in your stack.
Print Fulfillment
Printify (primary)
Better margins than Printful (~15–20% cheaper). Use Printful as fallback. Both have solid APIs.
Mockup Generation
Placeit API or Printify mockups
Auto-generate lifestyle photos for listings without manual Photoshop work.
Alerts / Monitoring
Resend (email) + Slack webhook
Failed orders, low margin warnings, and daily sales digests to your phone.
⚠ Key risks to design around

Etsy API rate limits: 10 req/sec, 10k/day. Scout agent must be throttled. Use cursor-based pagination, not parallel blasting.  ·  Design copyright: FLUX outputs are commercially safe if you own the prompt and don't reference specific artists. Avoid prompts that describe existing IP.  ·  Etsy ToS: Automated listing creation is allowed via the API — that's what it's for. Fully AI-generated art must be disclosed in listings (Etsy policy updated 2024).  ·  Margin math: Budget ~40–50% of sale price to Printify + Etsy fees. Price at 2.5–3× print cost minimum.
